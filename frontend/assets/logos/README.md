# Brand Logos

Drop the official brand logo image files here (PNG with transparent
background recommended, ~256px). The app loads them automatically; until
a file is present a clean branded fallback is shown.

Expected filenames:
- google.png   — Google "G" mark
- esewa.png    — eSewa logo
- khalti.png   — Khalti logo
- imepay.png   — IME Pay logo
- bank.png     — Bank / Connect-IPS logo
